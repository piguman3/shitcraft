# Shitcraft
LWJGL block game inspired by Minecraft

Currently targeting OpenGL 2.1 + extensions and Java 8

The goal is to just mess about with OpenGL and see if a (preferably multiplayer) Minecraft clone comes out of it in the process.

At the time of writing, ([commit d1d8999](https://github.com/piguman3/shitcraft/commit/d1d8999d9034ddde530c12448d34942061b593a1)) the game currently does nothing except render a rainbow triangle with code paraphrased from [learnopengl.org](https://learnopengl.com/).
